# ProGreen

Previsões de futebol: palpites grátis e área Super VIP.

## Baixar o app (Android 7.0 ou mais novo)

**[Baixar ProGreen.apk](https://github.com/Eusette/progreen/releases/latest/download/ProGreen.apk)**

### Como instalar
1. Toque no link acima e baixe o arquivo `ProGreen.apk`.
2. Abra o arquivo baixado. Se o Android avisar, permita "Instalar apps desconhecidos" para o navegador ou para o gerenciador de arquivos.
3. Toque em Instalar e abra o ProGreen.

Para atualizar, basta instalar a versão nova por cima.
